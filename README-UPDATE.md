# Cập nhật repo TrackingGxE

Upload **đè** các file sau lên root repo https://github.com/dar48305-design/TrackingGxE

- index.html          (bản mới: token mới + Bilka/Dagrofa/Auto)
- manifest.json
- sw.js               (cache v2 — buộc điện thoại lấy shell mới)
- icon-192.png        (giữ icon cũ của bạn)
- icon-512.png
- apple-touch-icon.png

## Cách update trên GitHub web

1. Vào repo → từng file → Edit (hoặc Add file) → upload/paste nội dung mới
2. Hoặc kéo cả thư mục này qua https://github.com/dar48305-design/TrackingGxE/upload/main

## Sau khi push

Trên điện thoại:
- Mở lại site Pages
- Nếu vẫn thấy bản cũ: xóa site khỏi Home Screen, xóa cache Safari/Chrome, hoặc đợi vài phút rồi Add to Home Screen lại
- Settings trong app: kiểm tra token + chọn Bilka/Dagrofa nếu cần
